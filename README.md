# SeatSave

**Library Table Reservation System**

SeatSave is a mobile app that lets students view real-time table availability in the library and reserve a table for a specific time. It helps students avoid walking around or waiting for an open table, especially during busy periods like exam week.

## Features

- Real-time table availability map
- Reserve a table for a specific time slot
- Advance booking (same day up to 3 days ahead)
- Maximum reservation duration of 3 hours
- No double-booking of the same table and time
- Filter tables by seating capacity or power outlet access

**Planned:** auto-cancellation for missed check-ins and reminders before a reservation ends.

## Getting Started

1. Install [Node.js](https://nodejs.org) (LTS) and the **Expo Go** app on your phone
2. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/group4-seatsave.git
   cd group4-seatsave
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the app:
   ```bash
   npx expo start
   ```
5. Scan the QR code with Expo Go (your phone and PC must be on the same Wi-Fi)
