# To-due List

To-due List is a personalized task management web application designed to help
students and professionals organize, track, and prioritize their daily tasks
and deadlines effectively.

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npx expo start`
4. Scan the QR code with Expo Go
